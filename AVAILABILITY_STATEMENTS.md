# Data and code availability

The public reproducibility materials contain a frozen, de-identified event-level table, annotation codebook, model-independent annotation constraints, analysis and figure code, compact numerical reference outputs and verification specifications. The table contains 256 event-states and preserves participant-specific narrative order using neutral identifiers. Transcript and excerpt text, specific-anchor text, contextual descriptions, original identifiers and historical production prompts are excluded.

The analysis code reproduces quantitative analyses from the frozen event table. Prospective annotation constraints describe the minimum methodological requirements for applying the framework to a new corpus; they are not historical production prompts or a guarantee of identical stochastic model outputs.

A repository URL and archival DOI should be cited after deposition. This package does not assert that deposition or complete local reproduction has already occurred.
